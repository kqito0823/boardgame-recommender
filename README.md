# ボードゲーム レコメンダー (Board Game Recommender)

AIを活用して、その日の気分やプレイ人数に合わせた最適なボードゲームを提案してくれるWebアプリケーションです。手持ちのボードゲームの管理機能も備えており、次に遊ぶゲーム選びや、新しいゲームの発掘をサポートします。

## 主な機能

### 1. AI ボードゲームレコメンド

ユーザーの入力（プレイ人数、希望ジャンル、自由記述の要望）をもとに、Google Geminiが最適なゲームを提案します。
- **今日遊ぶゲーム**: データベースに登録された「保有しているボードゲーム」の中から、今日のシチュエーションにぴったりのものを推薦します。
- **新しく買うゲーム**: 楽天市場商品検索APIと連携し、ユーザーの好みに刺さる新しいボードゲームをWeb上から検索して提案します。価格や購入リンク（楽天市場）も合わせて表示されます。

### 2. 保有ボードゲーム管理機能

自分の持っているボードゲームを一覧で管理できます。

- **CRUD操作**: ゲームの新規登録、編集、削除。
- **AI説明文生成**: ゲーム名を入力するだけで、AIが自動的に1〜2文の簡潔なゲーム説明・ルールを生成します。
- **プレイ記録**: 「遊んだ！」ボタンでプレイ回数と最終プレイ日を簡単に更新。
- **お気に入り機能**: お気に入りのゲームをハイライト表示。

## 技術スタック

- **フレームワーク**: Next.js 16 (App Router)
- **スタイリング**: Tailwind CSS v4
- **データベース・ORM**: PostgreSQL, Prisma
- **AI・外部API**: 
  - Google Gemini API (`gemini-2.5-flash`)
  - 楽天市場商品検索API
- **その他ライブラリ**: React Hook Form, Lucide React
